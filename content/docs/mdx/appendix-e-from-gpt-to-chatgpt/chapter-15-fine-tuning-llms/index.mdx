# 15. Fine-Tuning LLMs

## From General to Specific

After pre-training on massive data, GPT is general-purpose. **Fine-tuning** adapts it to specific tasks.

```
Pre-training:
  Data: 300B tokens
  Task: Next-token prediction
  Result: General understanding
  Time: Months
  Cost: Millions

Fine-tuning:
  Data: 10,000 examples
  Task: Task-specific next-token
  Result: Better performance
  Time: Hours
  Cost: Hundreds-thousands
```

## Instruction Tuning

Teach model to follow instructions:

```
Instruction: "Translate to French: 'Hello'"
Response: "Bonjour"

Instruction: "Summarize: [text]"
Response: "[summary]"
```

Training on diverse instructions makes learning generalize to new tasks.

## LoRA: Efficient Fine-Tuning

Full fine-tuning of 175B parameters requires massive memory and compute.

**LoRA** adds small adapter modules:

```
Instead of: W (175B parameters)
Add: A × B (millions of parameters)

Benefits:
✓ 99% less memory
✓ 100x cheaper
✓ 10x faster
```

Slightly reduces quality but tradeoff usually worth it.

## When to Fine-Tune

✓ Have task-specific data
✓ Want consistent outputs
✓ Need domain expertise

✗ Just need few-shot learning
✗ Data changes frequently
✗ Need flexibility
