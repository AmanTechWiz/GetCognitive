# 14. Context Windows and Scaling

## Context Windows

**Context window** = max tokens processable at once.

```
GPT-2: 1,024
GPT-3: 2,048
GPT-3.5: 4,096
GPT-4: 8,192 - 128,000
Claude 3: 200,000
```

With 4,096: Process 10-page document
With 200,000: Process entire book

Models use available context to override training knowledge.

## The KV Cache

### The Problem

Generating 100 tokens requires: 1+2+3+...+100 = 5,050 token computations (50x wasteful!).

### The Solution

Store Key and Value vectors. Reuse for future tokens:

```
Without: 5,050 computations
With: 100 computations
50x speedup!
```

Essential for practical inference.

## Why Larger Models Become Smarter

**Scaling law**: Performance improves predictably with size.

```
100M: Pattern matching
1B: Simple reasoning
10B: Multi-step reasoning
100B: Complex reasoning, code
1T: Very sophisticated reasoning
```

These abilities **EMERGED**—never explicitly programmed.

## Scaling in Practice

Scale model AND data together:
```
As compute increases: model_size ≈ dataset_size
```

## Current Limitations

**Context Length Tradeoff**:
- Longer context = more capability
- But attention is O(n²)
- 10x longer = 100x more memory

**Scaling Limits?** Unknown if we hit limits or can keep scaling to AGI.
