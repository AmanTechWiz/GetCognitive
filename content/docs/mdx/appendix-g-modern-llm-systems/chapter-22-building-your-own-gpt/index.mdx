# 22. Building Your Own GPT

## Training a Tiny GPT

Understanding by doing. Build a small GPT to learn how it works.

### Step 1: Prepare Data

```
Source: Shakespeare (~1M characters)
Tokenize: Character-level
Vocabulary: ~65 tokens
```

### Step 2: Tiny Architecture

```
Embedding size: 384 (vs 12,288 for GPT-3)
Heads: 6 (vs 96)
Layers: 6 (vs 96)
Parameters: ~10M (vs 175B)
```

### Step 3: Training Loop

```
For each batch:
  - Forward pass
  - Calculate loss
  - Backpropagation
  - Update weights
```

Observe loss decrease over epochs.

### Step 4: Inference

```
Start with prompt
For each token:
  - Get prediction
  - Sample next token
  - Append
  - Continue
```

Output: Syntactically reasonable text!

## Scaling Up

```
Tiny (10M): Laptop, hours
GPT-2 (1.5B): Good GPU, days
GPT-3 (175B): Thousands of GPUs, months
```

### Scaling Pattern

```
10x params → 3-4x better
100x params → 10x better
1000x params → 30x better
```

## Practical Considerations

### When to Train from Scratch

✓ Massive data (billions of tokens)
✓ Large budget (millions of dollars)
✓ Very specific domain

✗ Limited data
✗ Limited budget
✗ Need quick solution

Instead: Use pre-trained + fine-tune or RAG.

### Debugging

```
Loss not decreasing:
  ✓ Check learning rate
  ✓ Verify data loading
  ✓ Check gradients

Overfitting:
  ✓ More regularization
  ✓ Larger dataset
  ✓ Smaller model

Underfitting:
  ✓ Larger model
  ✓ Train longer
  ✓ Better hyperparameters
```

## Key Takeaways

1. Start small to understand
2. Use existing work (don't reinvent)
3. Iterate fast
4. Understand bottlenecks before optimizing
5. Know when to scale

Building your own GPT teaches everything about how modern LLMs work.
