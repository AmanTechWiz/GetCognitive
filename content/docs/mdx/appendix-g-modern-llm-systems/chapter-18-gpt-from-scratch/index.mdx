# 18. GPT From Scratch

The best way to understand GPT is to build one — every single piece, from raw text to generated tokens, with no magic. This chapter does exactly that using only NumPy.

By the end you'll have run a full forward pass: tokenize → embed → attend → feed-forward → predict next token.

---

## Step 1 — Tokenize

Split text into a vocabulary of characters. Each character maps to an integer ID.

## Step 2 — Embeddings

Each token ID is looked up in a learned table to get a dense vector. Position is added separately so the model knows token order.

```notebook

    {
      "id": "emb-1",

      "source": "VOCAB_SIZE = 13\nD_MODEL    = 8    # tiny embedding dim\nSEQ_LEN    = 8    # context window\n\ntoken_emb = np.random.randn(VOCAB_SIZE, D_MODEL) * 0.02\npos_emb   = np.random.randn(SEQ_LEN,   D_MODEL) * 0.02\n\n# First 8 tokens of our corpus\nx_ids = np.array(tokens[:SEQ_LEN])          # (8,)\nx     = token_emb[x_ids] + pos_emb          # (8, 8)\n\nprint('token ids :', x_ids)\nprint('x shape   :', x.shape)\nprint('x[0]      :', x[0].round(4))",
```

## Step 3 — Causal Self-Attention

Every token looks at every token before it (not after — that would be cheating). The causal mask enforces this by setting future positions to −∞ before softmax.

```notebook
{
  "title": "Step 3 — Causal Self-Attention",
  "runtime": "NumPy only",
  "cells": [
    {
      "id": "attn-1",
      "type": "code",
      "source": "def softmax(x):\n    e = np.exp(x - x.max(axis=-1, keepdims=True))\n    return e / e.sum(axis=-1, keepdims=True)\n\nD_K = 4   # head dim\nWq = np.random.randn(D_MODEL, D_K) * 0.02\nWk = np.random.randn(D_MODEL, D_K) * 0.02\nWv = np.random.randn(D_MODEL, D_K) * 0.02\n\nQ, K, V = x @ Wq, x @ Wk, x @ Wv    # (8, 4) each\n\nscores = Q @ K.T / np.sqrt(D_K)      # (8, 8)\n\n# Causal mask: token i can only attend to positions <= i\nmask   = np.tril(np.ones((SEQ_LEN, SEQ_LEN)))\nscores = np.where(mask, scores, -1e9)\n\nweights = softmax(scores)             # (8, 8)\nout     = weights @ V                 # (8, 4)\n\nprint('attention weights (row 3):', weights[3].round(3))\nprint('                          --> positions 4-7 are all 0 (masked)')\nprint('output shape:', out.shape)",
      "outputs": [
        {
          "type": "text",
          "content": "attention weights (row 3): [0.251 0.249 0.252 0.248 0.    0.    0.    0.   ]\n                          --> positions 4-7 are all 0 (masked)\noutput shape: (8, 4)"
        }
      ]
    }
  ]
}
```

## Step 4 — Feed-Forward Block

After attention, each token passes through a small 2-layer MLP independently. The hidden dim is 4× the model dim — same ratio as GPT-2.

```notebook
{
  "title": "Step 4 — Feed-Forward Network",
  "runtime": "NumPy only",
  "cells": [
    {
      "id": "ffn-1",
      "type": "code",
      "source": "def gelu(x):\n    return 0.5 * x * (1 + np.tanh(np.sqrt(2/np.pi) * (x + 0.044715 * x**3)))\n\nD_FF = D_MODEL * 4   # 32\nW1 = np.random.randn(D_MODEL, D_FF) * 0.02\nW2 = np.random.randn(D_FF,    D_MODEL) * 0.02\n\n# Project attention output back to D_MODEL via W_o, then residual + FFN\nW_o  = np.random.randn(D_K, D_MODEL) * 0.02\nh    = x + out @ W_o          # residual stream 1  (8, 8)\nh    = h + gelu(h @ W1) @ W2  # residual stream 2  (8, 8)\n\nprint('after FFN shape:', h.shape)\nprint('mean activation:', round(float(h.mean()), 6))",
      "outputs": [
        {
          "type": "text",
          "content": "after FFN shape: (8, 8)\nmean activation: 0.000318"
        }
      ]
    }
  ]
}
```

## Step 5 — LM Head & Next-Token Prediction

Project the final hidden states back to vocabulary size, apply softmax, and take the argmax. With random weights this is gibberish — but the shape and mechanics are exactly what GPT runs at inference time.

```notebook
{
  "title": "Step 5 — LM Head",
  "runtime": "NumPy only",
  "cells": [
    {
      "id": "lmhead-1",
      "type": "code",
      "source": "# Weight-tied: reuse token_emb as the projection matrix (GPT-2 does this)\nlogits = h @ token_emb.T     # (8, vocab_size=13)\nprobs  = softmax(logits)     # (8, 13)\n\npred_ids   = probs.argmax(axis=-1)\npred_chars = decode(pred_ids.tolist())\n\nprint('input   :', decode(x_ids.tolist()))\nprint('greedy  :', pred_chars)\nprint()\nprint('probs at position 0:', probs[0].round(3))\nprint('  → next token predicted:', repr(itos[pred_ids[0]]))",
```

## Putting It All Together

Here's the complete single-layer GPT forward pass in one cell — everything above, condensed.

```notebook
{
  "title": "Full Forward Pass (single layer)",
  "runtime": "NumPy only",
  "cells": [
    {
      "id": "full-1",
      "type": "code",
      "source": "import numpy as np\nnp.random.seed(0)\n\n# ── Config ──────────────────────────────────────────────────────────\nVOCAB = sorted(set(\"to be or not to be that is the question\"))\nV, D, T, Dk, Dff = len(VOCAB), 8, 8, 4, 32\nstoi = {c:i for i,c in enumerate(VOCAB)}\nitos = {i:c for c,i in stoi.items()}\ntokens = [stoi[c] for c in \"to be or not to be that is the question\"]\n\n# ── Weights ─────────────────────────────────────────────────────────\nWte = np.random.randn(V, D)  * 0.02   # token emb\nWpe = np.random.randn(T, D)  * 0.02   # pos emb\nWq  = np.random.randn(D, Dk) * 0.02\nWk  = np.random.randn(D, Dk) * 0.02\nWv  = np.random.randn(D, Dk) * 0.02\nWo  = np.random.randn(Dk, D) * 0.02\nW1  = np.random.randn(D, Dff)* 0.02\nW2  = np.random.randn(Dff, D)* 0.02\n\n# ── Forward ─────────────────────────────────────────────────────────\ndef softmax(x): e=np.exp(x-x.max(-1,keepdims=True)); return e/e.sum(-1,keepdims=True)\ndef gelu(x):    return 0.5*x*(1+np.tanh(np.sqrt(2/np.pi)*(x+0.044715*x**3)))\n\nids = np.array(tokens[:T])\nx   = Wte[ids] + Wpe                                      # embed\nQ,K,V_ = x@Wq, x@Wk, x@Wv\nscores  = np.where(np.tril(np.ones((T,T))), Q@K.T/Dk**.5, -1e9)\nx = x + softmax(scores)@V_@Wo                             # attention + residual\nx = x + gelu(x@W1)@W2                                     # FFN + residual\nlogits = x @ Wte.T                                         # LM head\n\npred = ''.join(itos[i] for i in logits.argmax(-1))\nprint('input :', ''.join(itos[i] for i in ids))\nprint('pred  :', pred)\nprint('logits:', logits.shape, '→', V, 'token probs per position')",
      "outputs": [
        {
          "type": "text",
          "content": "input : to be or\npred  : renqtqen\nlogits: (8, 13) → 13 token probs per position"
        }
      ]
    }
  ]
}
```

A real GPT stacks 12–96 of these transformer blocks, uses multi-head attention across many heads in parallel, applies layer norm before each sub-block, and trains on hundreds of billions of tokens. But this is the **exact same computation** — just repeated and scaled.
