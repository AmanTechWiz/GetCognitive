# 8. Attention and Self-Attention

## Query, Key, Value

Attention answers: **"Given a query, which values should I focus on?"**

Think of a search engine: query tells us what to search for, keys are document topics, values are document contents.

## Self-Attention

Self-attention applies attention within a single sequence: each token learns to attend to other tokens in the same sequence.

The model learns these patterns during training—no hard-coded rules. A verb naturally learns to attend to its subject.

## Scaled Dot-Product Attention

```
Attention(q, K, V) = softmax(q · K^T / √d) V
```

**Process**:
1. Compute similarity: q · K^T
2. Scale by √d (prevent too-large values)
3. Convert to probabilities: softmax
4. Weight values: multiply by softmax result

The √d scaling keeps dot products in reasonable range, creating soft probability distributions.
