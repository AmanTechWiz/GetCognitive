# 7. Why Transformers Changed Everything

## The Paper

In June 2017, "Attention Is All You Need" proposed a new architecture based entirely on **attention mechanisms**.

Key insight: **"Recurrence is not necessary. Parallelization is all you need."**

## The Problem with Recurrence

RNNs process sequences sequentially. To generate token 100, you must compute tokens 1-99.

For a 2000-token document:
- RNN: 2000 sequential steps
- Transformer: Process all 2000 tokens in parallel

**100x faster training!**

## Why Attention Replaced Recurrence

In RNNs, information degrades over time. With attention, each token can **directly access any previous token** without degradation.

This direct access to pristine information was revolutionary.

## The Breakthrough

Transformers showed:
1. Recurrence isn't necessary
2. Parallelization is possible
3. Attention alone is powerful enough
4. Scaling laws apply: bigger models = better performance

Within 5 years, transformers dominated every benchmark. RNNs became obsolete.
