# 10. Inside a Transformer Block

## The Components

A transformer block stacks:
```
Input
  ↓
Multi-Head Self-Attention
  ↓
Add & Normalize (residual + layer norm)
  ↓
Feed Forward Network
  ↓
Add & Normalize (residual + layer norm)
  ↓
Output
```

## Residual Connections

Deep networks are hard to train. Residual connections allow gradients to bypass layers:
```
x_out = x_in + MultiHeadAttention(x_in)
```
This enables training 96+ layer networks.

## LayerNorm

Normalizes activations to have mean 0, std 1. Keeps training stable.

## Feed Forward

Simple network: expand → ReLU → project back. Applied independently to each token. Stores much of the model's "knowledge."

## Encoder vs Decoder

**Encoder**: Each token attends to all (including future)
**Decoder**: Each token attends to past only (masked)

Ensures causal generation—model can't cheat by looking ahead.

## Complete Transformer

Tokens → Embeddings → Positional Encoding → Many transformer blocks → Vocabulary projection → Softmax

Each block refines representations. Higher layers capture more abstract patterns.
