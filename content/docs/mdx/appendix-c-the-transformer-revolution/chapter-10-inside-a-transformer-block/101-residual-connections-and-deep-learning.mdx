# 10.1 Residual Connections and Deep Learning

## The Problem with Deep Networks

As networks get deeper, gradients become exponentially smaller during backpropagation. This makes training very deep networks (50+ layers) nearly impossible.

```
Layer 100 output → compute error
    ↓ backprop (chain rule multiplies small numbers)
Layer 50 gradients (smaller)
    ↓ backprop (chain rule multiplies small numbers)
Layer 1 gradients (nearly zero)
```

Early layers receive almost no learning signal, staying near random initialization.

## Residual Connections

The solution is **residual connections** (skip connections), which allow gradients to bypass layers:

```
Original path: Input → Layer1 → Layer2 → Output
Residual path: Input ────────────────────→ (added to Output)

Final output = Layer2(Layer1(Input)) + Input
```

## Mathematical Formulation

```
x_out = x_in + f(x_in)
```

Instead of learning the full transformation `f`, the network learns the **residual** (difference). This is easier—the network only needs to learn small adjustments.

## Why It Works

1. **Gradient flow**: Gradients can bypass layers through the residual path
2. **Easier optimization**: Learning small adjustments is easier than learning full transformations
3. **Enables depth**: We can now train 96+ layer networks effectively
4. **Implicit regularization**: Forces network to learn meaningful transformations

For language models with 96 transformer blocks, residual connections are essential.

## Implementation in Transformers

```
x_out = x_in + MultiHeadAttention(LayerNorm(x_in))
y_out = y_in + FeedForward(LayerNorm(y_in))
```

Both attention and feed-forward layers use residual connections.
