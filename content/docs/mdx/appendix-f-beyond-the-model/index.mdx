# Appendix F — Beyond the Model

Language models are powerful, but they're limited:
- They only know what they were trained on
- They can't execute code or call APIs
- They can't access real-time information
- They generate text but can't take actions

This appendix covers technologies that extend LLMs beyond pure text generation.

**Embeddings + Vector Databases + RAG** let models access current information.
**Tool calling** lets models take action in the world.

Together, these transform language models from text generators into intelligent agents capable of real-world tasks.
