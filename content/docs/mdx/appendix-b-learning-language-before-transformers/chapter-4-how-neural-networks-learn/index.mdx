# 4. How Neural Networks Learn

A neural network is a massive mathematical function with billions of learnable parameters.

## The Forward Pass

Data flows through layers with learnable weights and non-linear activations, producing a prediction.

## Loss: Measuring Error

After prediction, calculate how wrong the model was using cross-entropy loss. Lower loss = better prediction.

## Backpropagation

Using the chain rule, calculate how much each weight caused the error. Then adjust weights:
```
weight_new = weight_old - learning_rate * gradient
```

## Training Loop

Repeat: forward pass → calculate loss → backpropagate → update weights

After millions of iterations across entire training set, weights are tuned to make accurate predictions.

## The Learning Rate

How much to adjust weights each step. Too high = unstable. Too low = slow training.

This cycle of predicting, calculating error, and adjusting is what allows neural networks to learn.
