# 6. RNNs and LSTMs

## RNNs

Recurrent Neural Networks maintain a **hidden state** that contains information about everything seen so far. Information flows backward in time.

The hidden state acts as memory, allowing the network to learn long-range dependencies.

## The Vanishing Gradient Problem

When backpropagating through many time steps, gradients become exponentially smaller. Early tokens have almost no influence on learning. RNNs only worked well with short sequences (5-20 tokens).

## LSTMs: A Solution

**Long Short-Term Memory** networks use **gates** to control information flow:
- **Forget Gate**: What to forget from memory
- **Input Gate**: What new information to add
- **Output Gate**: What to output

This allowed learning longer-range dependencies (50-100 tokens) through better gradient flow.

## Their Limitations

Despite improvements:
- **Sequential Processing**: Must compute step-by-step
- **Limited Attention**: Information compressed into fixed hidden state
- **Gradient Issues**: Still suffers with very long sequences
- **No Parallelization**: Can't use GPU effectively

By 2016, something better was needed. The question: **What if we let every position attend to every other position simultaneously?**

This question led to transformers.
