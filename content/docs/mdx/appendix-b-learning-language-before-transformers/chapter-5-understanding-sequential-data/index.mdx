# 5. Understanding Sequential Data

Language is fundamentally sequential: words appear one after another. The meaning depends on **order**:
- "Dog bites man" ≠ "Man bites dog"

Predicting future words depends on past context.

## Why Feed-Forward Networks Fail

Feed-forward networks treat each position independently. They have no way to know that position 2 depends on position 1.

For language, this is catastrophic—incoherent predictions.

## Motivation for Sequence Models

We need an architecture where:
1. Information flows forward
2. State persists (network maintains "memory")
3. Dependencies are captured

This motivation led to **Recurrent Neural Networks (RNNs)**: networks where information can flow backward in time.

The challenge: How do we make a network that remembers the past but remains trainable?
