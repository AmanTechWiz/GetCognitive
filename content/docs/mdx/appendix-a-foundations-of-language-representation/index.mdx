# Appendix A — Foundations of Language Representation

Before we can understand how large language models work, we need to understand the most fundamental problem: **how do we represent language in a way that computers can process?**

This appendix covers the foundational concepts that make modern AI possible. We'll explore why language is inherently difficult for machines, how text is converted into numerical representations, and how those representations capture semantic meaning.

Understanding these concepts is essential because:
- **Tokens** determine how language is broken down
- **Embeddings** are how meaning is encoded into numbers
- Everything that follows—from attention to generation—operates on these representations
