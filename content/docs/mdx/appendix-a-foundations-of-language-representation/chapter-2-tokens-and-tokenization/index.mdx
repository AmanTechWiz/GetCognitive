# 2. Tokens and Tokenization

A **token** is the fundamental unit that language models process. Modern language models use **subword tokenization**, breaking text into pieces smaller than words but larger than characters.

## Why Tokenization is Needed

1. **Vocabulary Management**: Reduces millions of words to 50,000-100,000 tokens
2. **Consistent Processing**: Enables fixed-size numeric input sequences
3. **Efficient Computation**: Fast array indexing into embedding tables
4. **Language Universality**: Same approach works across all languages

## How It Works

Modern tokenizers like Byte Pair Encoding:
1. Start with characters
2. Repeatedly merge frequent adjacent pairs
3. Continue until vocabulary reaches desired size

## Vocabulary and Token IDs

Each token gets a unique integer ID. Text becomes token ID sequences that the model processes.
